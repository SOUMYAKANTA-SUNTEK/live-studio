## Download and run (Windows 10/11)

1. Download **LiveStudio-Windows.zip** below and unzip it somewhere permanent (for example `Documents\Live Studio`).
2. Open the folder and double-click **Live Studio.exe**.
3. If Windows says "Windows protected your PC", click **More info**, then **Run anyway** (the app isn't code-signed yet).
4. Allow camera and microphone access, paste your YouTube stream key in the Stream tab and press **Go Live**.

See the README in the zip (or on the repo page) for the full guide.

## Highlights
- Studio, Broadcast and Classic layouts (webcam, scorebar, lineups on a pitch, ticker, info box, channel badge)
- Goals, cards and substitutions with on-screen pop-ups
- Half time / Full time buttons that hide the clock
- Reset starts a new match (score, clock, events, subs)
- Light mode encoder for low CPU and heat
